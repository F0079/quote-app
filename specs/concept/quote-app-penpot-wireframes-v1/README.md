# Quote App – Wireframes v1

Sechs Android-Ansichten, jeweils 390 × 844.

Import: SVG-Dateien in ein geöffnetes Penpot-Design ziehen oder über die SVG-Importfunktion einfügen. Einzelansichten sind für die Weiterbearbeitung gedacht; die Übersicht für die Besprechung. Texte sind SVG-Textobjekte, Flächen und Hintergründe Vektorformen. Keine eingebetteten Rasterbilder oder externen Schriften. Je nach Import können Gruppen angepasst werden müssen.

Ablauf: Start → Foto → Zitat → Editor → Export. Gestaltung ist eine Unteransicht des Editors. Alternativer Einstieg: Start → Zitat → Foto → Editor. Entwürfe öffnen direkt den Editor.

Dies ist ein statischer Entwurf: keine nativen Penpot-Komponenten, keine angelegten Klickverbindungen. Beispielzitate und Exportauflösung sind Platzhalter. Kamera/Galerie würden in der App Android-Systemoberflächen öffnen.

Zu prüfen: Platzierung der Autorennennung; Editor-Werkzeuge als Unteransichten oder Bottom Sheets; Umfang der ersten Version; kurzer Weg vom Entwurf zum Export.
